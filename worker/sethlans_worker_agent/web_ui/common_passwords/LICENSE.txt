common-passwords.txt.gz in this folder is copied unchanged from Django 5.2.4
(django/contrib/auth/common-passwords.txt.gz, SHA-256
3c1baed62596de36860824eb3f436d5932d37ca8b06e59df78f5a44ec175afe4).
Django's CommonPasswordValidator uses it; the worker page password rules
(web_ui/password_rules.py) check against the same list.

The list holds 20,000 common passwords (unhexed, lowercased and deduplicated),
created by Royce Williams:
https://gist.github.com/roycewilliams/226886fd01572964e1431ac8afc999ce
